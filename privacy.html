Privacy

Last updated 17 October 2026

In short

No cookies, no analytics, no advertising, no accounts, no tracking. Five of the six tools run entirely in your browser and never upload your files. Only the GIF → WebM tool sends the GIF to our own server in Switzerland, which deletes it right after converting it.

Your files

PNG → JPEG, Sticker 512, Emoji 100, Map splitter, 25 mm grid: the images are processed by your own browser. They are never sent anywhere.

GIF → WebM: converting needs software that does not run in a browser, so the GIF is uploaded to api.piogino.ch. The server converts it, sends the result back and deletes both files immediately; if a conversion is interrupted, leftovers are removed within one hour. Files are not looked at, kept or passed on. The request (IP address, time, address requested, browser details) is written to the server log, and the file name appears in the conversion log. Both logs serve operation and security only and are deleted after 14 days.

Stored in your browser

This site sets no cookies. It stores two things on your device:

  • preferred-theme in local storage: light or dark mode, if you changed it
  • a copy of the site's own pages, styles and scripts (no files of yours), so the tools also work offline

Neither is ever sent to us. You can delete both at any time by clearing the site data in your browser's settings, or use a private window; the site works the same without them.

Data abroad

GitHub is based in the USA, so your IP address and the page request reach the USA when the site is loaded. GitHub states that it participates in the Swiss-U.S. Data Privacy Framework; for details see its privacy statement linked above. Our own server, and therefore any GIF you convert, is in Switzerland.

Your rights

Under the Swiss Federal Act on Data Protection (FADP) you can ask what personal data about you is processed, and have it corrected or deleted. Write to info@piogino.ch. As files are deleted straight away, we cannot tell who is behind an IP address and logs are deleted after 14 days, there is usually nothing we can link to you. You can also contact the Federal Data Protection and Information Commissioner (FDPIC).

Changes

This statement is updated when the site changes; the date at the top shows the current version.
