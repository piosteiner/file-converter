In Procreate

  1. New canvas with the same pixel size and 150 DPI.
  2. Actions → Add → Insert a file → this PNG.
  3. Keep the grid as the top layer, lock it and lower its opacity.

Scale

At 150 DPI a 25 mm square is 147.6 px. Line positions are rounded per line rather than per square, so the error never adds up across the map.
